### Description

```
想要一整座 MC 城市，又不想一栋一栋手动摆？

在存档里建几栋建筑，每栋用三个方块做好标记，MC CityGen 就能按这个风格生成一座完整的城市：主干道和街道纵横交错，房屋沿街排列，地标点缀其间。生成后可以直接作为存档打开游玩，也可以导出 .schem 文件，放进自己的世界。

上手就能生成
• 自带现代和中世纪两套手工素材包，不用自己建也能生成第一座城市。
• 示例存档已准备好，依次点击“提取”“预览”“建造”即可。

用自己的建筑
• 在建筑的对角放上金块和钻石块，在地面高度放上绿宝石块，就完成了标记。
• 叠放三个标记好的模块，楼高会随城市需要自动调整。
• 现代高楼也好，中世纪城墙也好，你建什么风格，城市就是什么风格。

先预览，再建造
• 先看路网和建筑布局，满意了再开始建造。
• 每次建造都会生成一张全城效果图。

按你的想法调整
• 五档城市规模，从小村庄到大都市。
• 可调整路网密度、主干道和街道间距、弯道、丁字路口和建筑搭配。
• 换个种子就是一座新城市，记下种子还能再次生成同一座城市。

无需注册
• 可离线使用。无需账号，没有广告，不收集数据。
• 基于 Apache 2.0 许可证开源。

系统要求与限制
• Windows 10 或 11（64 位）。
• 游玩生成的城市需要 MC Java 版 26.1.2 或更高版本；运行本应用不需要安装 MC。
• 建筑必须朝南。

NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.
```
