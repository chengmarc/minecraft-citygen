### Description

```
街づくりの一番大変な作業を、アプリにおまかせ。

MC CityGen は、MC で建てた数軒の建物をお手本に、街全体を自動で作るアプリです。道路を引き、家を並べ、ランドマークを配置するところまで、すべて任せられます。

はじめての方も、インストールしてすぐに試せます。現代風と中世風の素材セット、サンプルワールドが付属しているので、ボタンを 3 回押すだけで最初の街が完成します。

自分の建物を使うのも簡単です。建物の角に金ブロックとダイヤモンドブロック、地面の高さにエメラルドブロックを置くだけ。建物を 3 段に分けておけば、街に合わせて高さも変わります。ビルを建てれば都会に、城壁を建てれば中世の町に。作った建物の雰囲気が、そのまま街の雰囲気になります。

建設の前には道路と建物の配置を確認でき、気に入らなければシードを変えて何度でもやり直せます。規模は小さな村から大都市まで 5 段階。道路の密度や間隔、曲がり角の数も細かく調整できます。同じシードを使えば、同じ街をもう一度作ることもできます。

完成した街は、そのまま遊べるワールドとして開けるほか、.schem ファイルで自分のワールドに持ち込めます。全体を見渡せる完成イメージも毎回作られます。

オフラインで動作し、アカウント登録、広告、トラッキングは一切ありません。ソースコードは Apache 2.0 ライセンスで公開しています。

動作環境と注意事項
• Windows 10 / 11（64 ビット）
• 作った街で遊ぶには MC Java Edition 26.1.2 以降が必要です（アプリの実行には不要です）
• 建物は南向きに建ててください

NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.
```
